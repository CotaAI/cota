# 价值观与科学审校：所有绘本共用

这些是本Skill的编辑原则；下列来源支持其中的儿童发展与健康指导，不代表任何机构逐条认证本Skill。价值判断与可检验科学事实分开，不借“科学”之名宣称唯一正确审美、家庭文化或人生选择。

## 尊重与关怀

- 儿童有尊严、表达和求助的权利；爱与归属不能以听话、优秀、漂亮或成功为条件。
- 情绪可以被接纳，伤害行为需要被制止。“你很生气，我会陪你；我不能让你打人，我们先退一步。”既有共情也有边界。
- 身体边界适用于自己和他人：邀请、触碰、拥抱、分享都应尊重意愿；必要照护由成人解释并支持，不能用身体自主当作放任伤害的理由。
- 公平不等于每个人永远得到相同东西；可以呈现不同需要和合理帮助。尊重家庭、文化、性别、能力、外貌和生活条件的差异。
- 成人也会犯错、道歉、调整。孩子不负责让所有大人开心，不为被伤害或生病承担道德责任。
- 鼓励诚实、好奇、合作、同理心、可承担的责任与照顾自然。以行动和后果呈现，不把每本书变成训诫。
- 尊重伤者和动物；幽默不建立在霸凌、羞辱、歧视或痛苦上。不把暴力、权力压制或财富当作天然正确。

## 行为引导

理解孩子的需要、能力与环境，再设计替代动作。展示成人示范、共同调节、等待、重复练习和具体反馈；允许改进有反复，不承诺“一本绘本纠正习惯”。

不以“警察来抓你、医生打针惩罚你、爸爸妈妈不要你、你不睡就生病”等恐吓驱动行为。自然后果须合理、相关、适龄；不能让角色故意遭危险来“长记性”。必要安全边界由成人承担，不要求幼儿仅靠自控避免风险。

积极反馈要具体，如“你把通道让开了，她可以过去”，避免“乖孩子都这样”“男孩不能哭”“你真聪明所以每次都赢”。

## 事实、比喻、幻想与信念分开

| 内容 | 可采用 | 需要防止 |
|---|---|---|
| 现实事实 | 简化名称、选择关键步骤、说明适用条件 | 改变因果、遗漏会误导的前提、必然化概率 |
| 科学比喻 | 白细胞像巡逻员，电网像道路 | 把比喻机制当事实，画面暗示细胞等孩子睡了才工作 |
| 幻想 | 月亮讲话、飞龙、梦中旅行 | 要求每个魔法都科学解释；把魔法当现实操作建议 |
| 传统/文化/信仰 | “这个传说里……”“有些家庭相信……” | 冒称经实验证实，贬低别的家庭 |
| 价值与选择 | 尊重、关怀、提出理由、容许讨论 | 以权威代替理由，规定所有人只能有一种感受 |

故事的类别应从封面简介、语境或必要的一句说明中清楚可辨；不必每页加破坏阅读的免责声明。健康和安全结论在儿童正文内就要准确，不能靠家长页撤回错误。

## 科学核验方法

1. 在分镜前列出现实主张，特别标出“只有、一定、马上、永远、导致、治好”等措辞与相邻画面的因果暗示。
2. 按问题寻找可靠来源：科学机构/研究、儿科和公共卫生机构、相关领域专业组织、官方技术资料；以适龄共识为主。单个成人实验不能直接变成幼儿疗效保证，商业宣传不替代证据。
3. 保存来源标题、直接链接、查阅日期、支持的具体结论、对象与条件、不确定性。关键健康、安全、争议或变化信息在当前项目重新核对，查不到就降低确定性或删除。
4. 用儿童语言改写后再反向核对：省掉的是术语还是改变了意思？图解中的数量、位置、方向、步骤和前后对比是否仍正确？
5. 对重要错误先修正再交付。不确定的诊疗建议不自行编造；绘本提供一般认识和求助，不替代个体诊断或处方。

## 典型改写与图画要求

| 不采用 | 推荐表达/呈现 |
|---|---|
| 只有睡着，身体才修复；一觉伤口一定好 | “身体白天晚上都在照顾你。好好睡觉，能帮助身体保持健康。”展示持续修复，不作必然痊愈的前后图 |
| 没恢复是你没乖乖睡 | 恢复需要时间；不舒服请告诉大人，必要时就医 |
| 手机一看就长红血丝，红血丝都是手机造成 | 画具体的久盯屏幕和休息情景，核对眨眼、干涩等机制；不把症状归结为唯一原因 |
| 所有冷食都伤身体，糖就是毒 | 依据具体年龄、食物和情境核验，讲适量与习惯，不制造食物羞耻或虚假禁忌 |
| 别哭了，你要勇敢 | “你可以难过，我陪着你。”勇敢也可以是说害怕、求助和慢慢尝试 |
| 去世就是睡着/出去旅游 | 简洁说明死亡与身体停止工作，不将睡眠、短暂离开等同死亡；允许回忆、哭泣和反复提问 |
| 道歉后对方必须原谅 | 具体道歉和修复，给对方空间；不强迫拥抱或一起玩 |

## 逐页审校格式

保存 `内容审校.md`，每条记录：页码｜原句/画面｜事实/比喻/幻想/价值建议｜问题｜来源或编辑理由｜适用范围｜修订｜通过/待核对。检查无字画面、跨页转折和封面宣传，不仅检查正文。

关键健康错误、安全误导、羞辱/歧视、剥夺身体边界应修正；单纯版式建议或风格选择不冒充价值观红线。无法试读或实物打印时如实记录“待验证”，不能虚报完成。

## 参考依据与使用范围

以下于2026-10-28查阅；每本书需按实际主题补充来源。

- [NAEYC：适宜发展的实践](https://www.naeyc.org/resources/position-statements/dap/definition)：以优势、游戏与愉快参与为基础，结合个体和生活背景；用于年龄与个体适配，不作为统一发展进度表。
- [加拿大儿科学会：幼儿积极教养](https://caringforkids.cps.ca/handouts/behavior-and-development/positive-discipline-for-young-children)：用于温和、一致的边界、示范和技能学习。
- [美国儿科学会：有效教养政策](https://publications.aap.org/pediatrics/article/142/6/e20183112/37452/Effective-Discipline-to-Raise-Healthy-Children)：支持避免体罚、羞辱和侮辱，采用积极策略；不要求所有故事有教育结论。
- [NIH/NHLBI：睡眠为何重要](https://www.nhlbi.nih.gov/health/sleep/why-sleep-important)：支持睡眠与健康、免疫和儿童生长发育的联系，不支持“仅睡觉才修复”或“一夜痊愈”。
- [美国儿科学会：儿童如何理解死亡](https://www.healthychildren.org/English/healthy-living/emotional-wellness/Building-Resilience/Pages/How-Children-Understand-Death-What-You-Should-Say.aspx)：支持具体解释死亡、避免与睡眠混淆；个别案例仍要结合家庭情况。
