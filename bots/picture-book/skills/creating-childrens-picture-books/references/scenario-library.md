# 常见绘本场景与选择

本表是可扩展路由，不是封闭分类。题材、形式、阅读目的分开记录；一书选一个主类型，必要时叠加少量辅助标签。所有类型先读 [价值观与科学审校](values-and-evidence.md)，再读取下表主类型与实际涉及的辅助主题指南。不把所有绘本做成行为训练，不强制教育总结、答题或成人讲道理。

| 主类型（book_type） | 适用场景 | 叙事和画面重点 | 需要避免 |
|---|---|---|---|
| `everyday-story` [日常生活](themes/everyday-story.md) | 出门、买菜、做饭、普通一天 | 熟悉环境中的小发现、生活细节与节奏 | 把日常全部变成考核 |
| `behavior-story` [行为习惯](themes/behavior-story.md) | 等待、收拾、噪音、轮流 | 愿望→影响→具体替代动作→练习 | 羞辱、听话才值得爱、一读就改好 |
| `emotions` [情绪认识](themes/emotions.md) | 生气、害怕、嫉妒、失望 | 身体感受、情绪命名、陪伴和调节选择 | 禁止哭、生气即坏、立刻恢复快乐 |
| `relationships` [关系与边界](themes/relationships.md) | 友谊、分享、冲突、家庭、新手足 | 双方视角、同意、拒绝、修复和公平 | 强迫分享/拥抱/原谅、让弱者永远退让 |
| `transitions` [适应与变化](themes/transitions.md) | 入园、搬家、分离、看牙 | 具体流程、可预测安排、可信照料者 | 保证绝不会疼或害怕、逼独立 |
| `health-safety` [身体健康与安全](themes/health-safety.md) | 睡眠、卫生、营养、身体自主、交通 | 正确步骤、情景辨认、求助与成人责任 | 恐吓、替代诊疗、可模仿危险实验 |
| `science` [科学与工程](themes/science.md) | 自然、宇宙、身体、能源、机械 | 观察→提问→机制→应用；全景与细节对应 | 伪因果、拟人替代机制、术语堆砌 |
| `nature-ecology` [自然与生态](themes/nature-ecology.md) | 季节、动植物、栖息地、环保 | 观察与比较、生命联系、小范围可做行动 | 恶化动物形象、把环境责任压给孩子 |
| `concepts-math` [概念与数学](themes/concepts-math.md) | 颜色、数量、形状、时间、空间、分类 | 实物对应、可数图形、比较和多种解法 | 数图不符、为练算式打断故事、把快当聪明 |
| `language-literacy` [语言与阅读](themes/language-literacy.md) | 词汇、识字、韵律、双语 | 图义匹配、重复变化、朗读与语境 | 超龄识字压力、不自然翻译、机械注音 |
| `fantasy-adventure` [幻想与冒险](themes/fantasy-adventure.md) | 会说话的车、魔法、梦境、探险 | 世界规则、动机、惊奇、翻页悬念 | 把幻想机制当现实知识、奖励危险模仿 |
| `humor` [幽默](themes/humor.md) | 荒诞、误会、重复升级、反转 | 喜剧节奏、表情、视觉伏笔与笑点 | 嘲笑身体、口音、贫困、残障或受伤者 |
| `arts-poetry` [艺术与诗意](themes/arts-poetry.md) | 音乐、颜色、四季小诗、审美 | 意象、节奏、色彩和留白 | 强加唯一正确解释或结尾道理 |
| `culture-history` [文化与历史](themes/culture-history.md) | 节日、职业、地方生活、传说、人物 | 真实器物、多样日常；区分史实与传说 | 民族/职业刻板印象、传说冒充史实、虚构名言 |
| `identity-belonging` [自我与差异](themes/identity-belonging.md) | 身体差异、家庭形态、能力、归属感 | 每个角色的主体性、平等参与与可及环境 | 用外表标善恶、怜悯化或“治好才幸福” |
| `grief-loss` [失落与生命](themes/grief-loss.md) | 宠物去世、亲人离世、告别 | 简单诚实解释、允许悲伤、回忆与支持 | “死就是睡着”、孩子责任论、必须放下 |
| `personalized-memory` [个人纪念](themes/personalized-memory.md) | 生日、旅行、成长、家庭相册故事 | 用户提供的真实经历与温柔细节 | 擅自编造家庭事实、公开隐私 |
| `mixed` [混合/自定义](themes/mixed.md) | 上述多种或未列出的主题 | 写清主体验和辅助目标，按需扩充分类 | 同一本塞进过多目标 |

## 使用主题指南

每份主题指南均包含：指导思想、创作前判断、叙事与行为原则、图画与语言、边界与易错点、落地例子、验收问题、依据与核验。它们是实际制作约束，不只是题材介绍。

选定主题后，在项目中保存 `主题创作约定.md`：写明本书的主体验、适用指南、3—5条最相关原则、需要避免的误导、如何落实到情节和画面、专题核验项。简单项目也可把该节放入故事与分镜，避免重复文档。指南未涵盖的主题按同一结构补充，不机械套用。

共同底线优先；题材之间允许不同审美和结尾方式。例如幽默可以纯粹好笑，告别可以安静并保留悲伤，数学要让数量可核对，历史要让事实与传说可区分。参考来源及支持范围见[主题依据索引](theme-sources.md)。

## 形式标签（themes 可附加，亦可另记 format_tags）

- **无字绘本**：正文允许为空；以动作连续、视线、构图、伏笔和翻页完成叙事。成人共读提示可另附，不能侵占无字画面。验收时暂时移除成人旁白，检查是否仍能从图像理解关键因果，同时容许多种合理解读。
- **互动/找寻/推理**：图面提供足够线索；检查答案、数量与路径；允许开放问题，不把观察力等同智力。封闭题须逐图复核答案，找寻目标不能被裁切、中缝或错误遮挡隐藏；开放题不伪称只有一个答案。
- **翻翻/洞洞/触摸**：先明确真正制作能力和结构图，普通PDF不能假称具有实体机关；小零件、边缘和材料需成人制作及安全评估。交付制作图和操作顺序，并用实体原型检验开启、遮挡和装订；未制作原型须明确标为待验证。
- **睡前/安抚**：节奏逐渐放缓、低刺激画面、可预测重复；不保证每个孩子马上入睡。
- **连环/系列/分级**：继承角色设定但变化动作和构图；阅读难度按实际语言、篇幅和知识前提标示，勿冒用出版机构分级。
- **双语/多语**：确认主阅读语言和目标；避免一页文字翻倍导致拥挤，译文检查自然度与事实一致性。

## 年龄与个体适配

年龄只是起点，结合语言、经验、感官需求和亲子共读方式。婴幼儿可重节奏、指认与重复；学龄前以具体情景和短因果为主；更大儿童可增加多视角、证据与开放推理。不要把“三岁半男孩”的历史项目当成所有读者，也不按性别限制题材。没有必要把悲伤题材强画成欢乐：保持温柔、有支持感即可。
