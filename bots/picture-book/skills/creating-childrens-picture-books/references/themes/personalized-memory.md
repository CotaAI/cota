# 个人纪念、成长与家庭故事

主题标识：`personalized-memory`。与[共同价值观与科学审校](../values-and-evidence.md)一起使用；本指南为编辑方法，不是诊疗方案或儿童能力测评。


## 指导思想

帮助孩子看见自己的经历与关系，同时允许他拥有不同感受。纪念不是优秀表现档案，也不把家庭生活包装成完美模板。

## 创作前判断

整理用户提供的时间、人物、称呼、地点、照片与故事。区分已确认事实、模糊记忆、允许的艺术化改编；未知处留待确认，不擅自补出生、疾病或家庭关系。

## 叙事与行为原则

选择具有情感联系的片段，而非罗列每个里程碑。允许旅行疲惫、生日紧张等真实体验；成长可以是开始尝试或更会求助，不只更快更高更听话。

## 图画与语言

保持真实人物辨认特征和重要物件，照片引用需授权。拟真重绘不得冒称实拍纪实；图文让孩子也有声音，不全是成人评价。

## 边界与易错点

不公开住址、学校、完整生日、证件或医疗隐私等非必要信息；对外分享前按用途另核查。不要为美化回忆编造家人原话、亲密关系或共同活动。

## 落地例子

旅行相册记录“雨太大，我们在屋里搭小车站”，保留孩子失望后找到乐趣的过程，不把取消行程解释为孩子不听话。

## 验收问题

每个重要家庭事实可追溯吗？孩子的感受与家长视角有区分吗？分享版删除了非必要隐私吗？哪些画面是改编已说明吗？

## 依据与核验

依据索引D、I提供尊重与个体适配；家庭事实以用户材料为准，隐私保护是编辑约束，不冒称来自医学研究。
