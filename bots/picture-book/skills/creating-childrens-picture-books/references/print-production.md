# 印刷制作

## 本用户默认：封面、扉页和内文分开

适用于本用户后续所有主题绘本，除非当前请求另有指定。默认A4/A5成品纸、左侧环装，不由此推导为所有出版物的强制标准。

| 部分 | 正面 | 反面 | 分文件打印任务 |
|---|---|---|---|
| 独立前封纸，厚纸 | 封面 | 纯空白 | 01_前封面：1页，单面 |
| 独立扉页纸，内页纸 | 书名、小插图、可选短引语 | 默认纯空白 | 02_扉页：1页，单面 |
| 正文及结尾，内页纸 | 正常顺序 | 正常顺序 | 03_内文：双面 |
| 独立后封纸，厚纸 | 朝书内的一面纯空白 | 朝外的一面是封底 | 04_封底：1页，单面，装订时图朝外 |

扉页不得承担必须读到的故事开场；已有“故事型扉页”改版时，将原内容移到正文，另做书名扉页，保留故事。用户明确选择扉页双面时，可将第一正文页印在其背面，并重算全部页序/打印任务，不能直接删空白而沿用旧说明。

正文及结尾若为奇数面，在该内文任务末尾补一面纯空白，使内文占整张纸；该面与独立封底内侧的空白是不同的物理面。不得为了凑面数灌水或删故事。

## 内容页、PDF面与纸张

默认扉页单面时，设正文及结尾为N个内容面：
- 有内容的总面数 = N + 3（封面、扉页、封底）。
- 物理纸张数 = ceil(N / 2) + 3。
- 完整标准页PDF面数 = 2 × 物理纸张数。
- 必留空白：封面背面、扉页背面、封底内侧；N为奇数时再加内文末尾背面。

例：21面正文及结尾＋3个结构内容面＝24个有内容面；需要14张纸、28面标准页PDF，含4面空白。若正文为22面，也是14张纸、28面PDF，但只有3面空白。不得继续模糊写“24页含封面”。

空白页在清单中标 `blank: true` 和用途；PDF里必须真的空白，不画“此页留白”、页码、边框或打印指示。默认阅读PDF也保留这些空白，与实物翻页节奏一致。只有明确要求紧凑阅读版时才另出无空白版，并附独立页码映射。

## 文件命名与交付

**首选一个可直接转发的完整标准页PDF＋一段可复制的打印说明。** 不要求用户下载或转发压缩包。PDF含全部结构性空白，说明写清哪些物理纸用厚纸。工作单放在书外，不插到书前改变双面页序。分文件只在用户或店家需要分纸种操作时提供；源文件ZIP是可选归档，不是打印入口。

- `书名_A4标准页版.pdf` / `书名_A5标准页版.pdf`：含所有结构性空白，正常页序，每面1页；不叫“单页打印版”，避免与单面打印混淆。
- `书名_阅读版.pdf`：默认与标准页版相同结构，可以共用一个文件并说明。
- 可选分文件：`打印店交付/01_前封面_单面.pdf`、`02_扉页_单面.pdf`、`03_内文_双面.pdf`、`04_封底_单面.pdf`。01、02、04三个单面任务各含一个有内容页；内文含必要的末尾空白。
- 需要时另附 `00_打印制作说明.pdf`：图示前封面、扉页、正文首尾和封底；列每个文件页数、单双面、纸张、装订顺序、图朝向、缩放、总纸张数。工作单不装进绘本。
- 附结构页预览、页码/纸张正反面映射、可重建源文件；所有ZIP与链接同步更新，旧方案移入明确的历史存档。

完整PDF直印为默认；分文件印刷为备选，两者二选一，不重复印：
1. 完整标准页版：按正常顺序双面、每面1页，保留空白，不启用“跳过空白页”；首尾纸按映射换厚纸。空白背面自然形成单面结构页。
2. 分文件：按01至04分别设置单面/双面，厚薄纸分开，封底有图一面朝外。不能把四份直接连接后按统一双面设置打印，否则会破坏留白和纸张对应。

## 尺寸与装订

行为故事默认A5横版210×148毫米；科普拆分知识点后可用A5，结构密集时优先A4横版297×210毫米。竖版、方形、照片书或其他装订按具体需求选择。标准A4/A5纸无需设计裁切；普通打印机四周留约8—10毫米，装订侧检查打孔安全区。

一页PDF是一个面，不是一张纸。环装不要求4的倍数；骑马钉通常要求面数为4的倍数，独立厚封面时须确认4面封面＋内文结构，由印厂拼版。A4对折通常得到A5竖版，不能承诺简单对折得到常规左侧装订A5横版。本用户若改用骑马钉/胶装，保留结构意图，但按印厂模板另做拼版和封面，不套用环装纸张数。

## 打印参数与用纸

实际大小100%，纸张与PDF匹配，每面1页，不启用小册子、每面两页、无边距放大或跳过空白页。横向左侧装订通常选短边翻转，但必须注明尚待设备试印；未实测不能宣称确认。提供一张正反面方向测试纸，测试纸不编进成书。

家庭内页可用100—160克哑光纸、封面160—220克；打印店可参考内页120—160克、封面200—250克。设备进纸、纸张双面能力、透印和装订能力由实际服务方确认。正文默认双面，结构页默认单面不代表全书单面。

## 家庭、数码快印与专业印厂

家庭和数码快印可用RGB、嵌入字体的留白标准页PDF。专业印刷的出血（常见3毫米）、ICC/CMYK、书脊和纸张须按印厂规格；印厂版与家庭版分别命名，不能把家庭拼版交给印厂作为默认输入。插图目标通常300ppi，记录实际有效分辨率，不把插值放大描述为新增真实细节。

交付前检查：内容未丢失；真正独立扉页；结构性空白真的空白；封底朝外；分文件单双面与纸张数匹配；标题、页码、ZIP、说明和预览同步。未做实物试印如实写“待试印”，允许交付已验证数字文件，不能为通过脚本伪造测试结果。
