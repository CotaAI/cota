# 视觉与图文版式

开始批量制图前，确认当前环境的读图、参考图生成和图片编辑通路可用；首次使用或换工具时执行 [环境准备与图像工具接入](runtime-setup.md) 的样页验收。按实际工具接口传入参考图并读取生成结果，不以提示词、文件名或生成成功状态代替看图检查。

## 视觉圣经

正式出图前建立并保存：

- 角色正面、侧面、全身和常用表情参考；
- 固定服装、鞋子、发型、年龄比例和标志性道具；
- 主配色、背景复杂度、材质、光线和镜头语言；
- 场景空间关系，例如楼层、楼梯方向、汽车部件位置；
- 品牌规则：允许出现的标志、位置、次数和禁止出现的文字；
- 科普图例：箭头、放大框、危险标识和能量颜色的含义。

所有后续生成都引用角色参考图。不要只用角色名字反复重生成。

## 图文一体

“图文融合”是视觉关系，不要求把文字烘焙进图片像素。以下文字留白与排版步骤仅适用于有文字的页面；无字页面不强制预留正文区或添加文字。

1. 先为每页确定文字量和位置。
2. 绘图提示中指定负空间：天空、墙面、地板、被子、窗外或柔和渐变区域。
3. 插图完成后用排版层加入准确中文。
4. 文字颜色取自画面，但必须保持清晰对比；复杂背景可局部降对比或使用轻柔半透明底，不要默认白色大框。
5. 人物视线、动作方向和文字阅读方向应互相引导。
6. 不遮挡脸、手、身体接触点、机械连接、危险动作和科学路径。

全书混合使用：满版、跨页、单页大场景、连续小场景、局部特写、安静留白和图解页。不要全书固定“上图下文”。

## 背景与注意力

背景色调服从题材与情绪，日常轻松题材可明亮开朗，悲伤或安抚题材可柔和安静；低龄画面适度简化。每页只保留支持情节的环境元素；关键动作附近减少纹理。科普页面的真实设备可以更具体，但与解释无关的背景应弱化。

## 全景与放大图

当儿童可能不知道细节属于哪里时，使用“现实情景全图 → 一个箭头 → 放大细节图”。

- 全景中完整显示足以定位的身体或设备范围。
- 用一个圆圈标出观察点；一个放大关系只用一个方向明确的连接箭头。过程、循环或多部件图可保留必要的步骤箭头，避免与放大连接混淆。
- 每页全景动作和当页内容一致，不复制通用定位图。
- 细节图保留真实结构的关键关系，同时使用儿童友好的表情或视觉向导。
- 放大图不能只剩抽象结构；必要时加入真实外观小图、剖面和简化结构三者之一或组合。
- 箭头和文字不是装饰。若无需箭头即可理解，就省略。

## AI插图检查

逐图检查：角色脸型、服装、手指数量、手与物体接触、视线、镜像文字、设备结构、品牌标志、时间和楼层连续性。生成图中的中文、数字和logo默认不可信，应由排版层或受控素材覆盖。

图像编辑使用图像生成/编辑工具；裁切、拼版、色彩配置和文字排版使用确定性工具。保留原图、最终图和生成记录，避免反复压缩JPEG。

## 字体

使用有授权且嵌入PDF的中文字体。正文优先清晰黑体或圆体；全书一般不超过两个字体家族。根据实际尺寸打印样张确定字号，不只看屏幕。避免孤字、过长行、过小行距和低对比细白字。
