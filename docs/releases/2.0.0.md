# Cota 2.0.0

Cota 是 Bot 开发与部署平台：以 Skill 定义能力，以 Policy 引导业务决策，以可恢复的事件记录保存执行事实，并交付可独立运行的 Bot。

## 本版内容

- 执行引擎统一为官方 Pi Agent Core；复用 Pi 的 Skill 加载与原生工具，Cota 负责部署边界、业务引导和执行记录。
- DST 统一应用事件并支持重放恢复；Store 逐条保存事件、按需保存快照。Debug 页面集中查看执行事实、模型请求和当前状态。
- Policy 支持对话式业务标注、训练与推理。`cota eval` 提供 LLM 评测、进度输出、结构化结果和版本比较，为后续 RSI 提供基础。
- 接入保留 Web、飞书和命令行。Application 负责消息去重、会话内顺序执行及跨会话并发；身份与访问权限继续由外围应用提供。
- Web 支持持久化消息、断线恢复和有界同步；可选聊天应用提供会话列表、未读及阅读位置，阅读状态不写入 DST。
- 安装包仅保留 `weather` 示例，包含天气、活动查询和出行规划 Skill，以及 30 个评测案例。

## 安装与验证

本版以 GitHub 源码和 `v2.0.0` 标签发布，不附加二进制安装包，也不发布 PyPI。

需要 Python 3.12+ 和 Node.js（固定开发版本见 `.node-version`）。在仓库根目录的虚拟环境中执行：

```sh
python -m pip install -e '.[dev]'
npm ci --prefix cota/runtime/pi
cota init
cd cota_projects/weather
# 在 endpoints.yml 中配置模型后：
cota shell --debug
cota eval
```

平台 wheel 的构建能力保留，用于本地或 CI 安装验证；生成的运行时、wheel、数据库和模型密钥不提交 Git。

## 升级注意

这是不兼容旧版本的架构升级。请备份旧 Bot 与数据库，用 `cota init` 创建新项目，再迁移业务 Skill、Policy 和模型配置；旧 Action 配置和旧数据库 schema 不自动转换。

当前 Web 应用的执行协调采用单进程模型；多个 Worker 或实例共享同一个 Store 的分布式执行与跨实例广播不在本版支持范围内。外部 IM、登录与成员授权系统通过接入契约对接，Cota 不提供账号平台。
