# Root Bot Templates Implementation Plan

**Goal:** Maintain official templates only in root `bots/`, preserving pip installation and safe `cota init`.

**Architecture:** Source/editable installations resolve `bots/` relative to the imported Cota module, verifying the adjacent project metadata. Release wheels carry filtered files in `cota/_templates/bots/`. No lookup relative to the user's working directory. Existing generated `cota_projects/` directories remain unchanged.

**Tech Stack:** Python 3.12, Hatchling, pytest, existing bundled Pi runtime.

- [x] Add resolver tests for source, installed package, unrelated sibling directory, missing templates; retain init preservation and filtering coverage.
- [x] Move `cota/bots` to `bots`. Add `cota/templates.py` for resolution and shared copy/package exclusions; integrate CLI and wheel build hook.
- [x] Include root templates in sdist; update ignore rules, CI paths, docs and integration test roots.
- [x] Run template/integration/distribution tests. Build sdist and a wheel from that sdist, inspect exact template membership, install wheel and run offline installed smoke outside the repository.
- [x] Verify editable installation outside repository, inspect diff and record results.

Validation commands: `.venv/bin/python -m pytest tests/test_bot_templates.py tests/integration/test_example_bots.py tests/test_pi_distribution.py -q`; `uv build --sdist`; build wheel with existing `COTA_RUNTIME_DIR`; run `scripts/smoke_installed.py` from `/tmp` using installed environment. Artifact contents must match the 13 maintained files and exclude injected runtime/cache/environment fixtures.

## Validation results

- Focused template, actual Bot integration and runtime distribution tests: 30 passed (11 existing warnings).
- Source archive built and inspected: exactly 13 template files at `bots/`.
- Built a macOS arm64 release wheel from the extracted source archive. Added dummy environment, database, workspace, cache and Node dependency files before building; both resulting sdist and wheel excluded them all. Wheel carries exactly 13 files at `cota/_templates/bots/` and no old `cota/bots/`.
- Installed wheel outside the repository: CLI init, all three Bot templates and real Pi tool loop passed with network disabled and no system Node/npm. A decoy `bots/` in the working directory was ignored. External model responses were deterministic.
- Installed editable package into a temporary environment: init outside the checkout copied three Bots and preserved a user-edited configuration on repeated init.
- CI now watches root bots and builds sdist followed by wheel; cross-platform CI was configured, not executed locally.
- No runtime, DST or Store changes; user-generated `cota_projects/` remains unchanged. No commit or publication performed.
